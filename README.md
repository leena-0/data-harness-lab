# Data Harness Lab

Harness 100의 데이터 관련 하네스를 참고하여
데이터베이스·데이터 엔지니어링·분석·BI·ML을 실습하는 저장소입니다.

## 학습 목표

- 요구사항을 데이터 모델과 스키마로 변환하기
- 안전한 데이터 마이그레이션 설계하기
- ETL/ELT 파이프라인 구축하기
- 데이터 품질 검증과 모니터링 적용하기
- SQL 분석과 시각화 수행하기
- KPI와 BI 대시보드 설계하기
- ML 실험과 데이터 버전 관리 경험하기
